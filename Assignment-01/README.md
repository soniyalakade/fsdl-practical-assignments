# Assignment 01 – PCCOE College Enquiry

A web form where visitors submit enquiries; they are saved to MongoDB and can be listed back.

- **Stack:** HTML, CSS, Node.js, Express 5, MongoDB driver, dotenv
- **API:** `POST /api/enquiries`, `GET /api/enquiries`
- **Original repo:** https://github.com/soniyalakade/FSDL5

## Run locally

```bash
cd source-code
npm install
echo "MONGO_URI=<your-mongodb-connection-string>" > .env
npm start
```
