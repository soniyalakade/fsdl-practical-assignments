# Assignment 02 – Appointment Booking

A booking page that shows available slots and stores appointments in MongoDB.

- **Stack:** HTML, CSS, Node.js, Express 5, MongoDB driver, dotenv
- **API:** `GET /api/slots`, `POST /api/appointments`, `GET /api/appointments`
- **Original repo:** https://github.com/soniyalakade/FSDL6

## Run locally

```bash
cd source-code
npm install
echo "MONGO_URI=<your-mongodb-connection-string>" > .env
npm start
```
