# Assignment 03 – Feedback App (React + Express + MongoDB)

A full-stack feedback application with create, read and delete operations.

- **Stack:** React, Vite, Node.js, Express, MongoDB
- **API:** `GET /api/feedback`, `POST /api/feedback`, `DELETE /api/feedback/:id`
- **Original repo:** https://github.com/soniyalakade/FDSL7

## Run locally

```bash
# backend
cd source-code/backend
npm install
echo "MONGO_URI=<your-mongodb-connection-string>" > .env
node server.js

# frontend (new terminal)
cd source-code/frontend
npm install
npm run dev
```
