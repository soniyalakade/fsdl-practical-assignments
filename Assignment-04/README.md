# Assignment 04 – devTinder Web

React client for a developer-matching app, with login, feed, user cards, connections, requests, and profile editing.

- **Stack:** React 19, Vite, Redux Toolkit, React Router, Tailwind CSS 4, DaisyUI
- **Original repo:** https://github.com/soniyalakade/devTinder_web

## Run locally

```bash
cd source-code
npm install
npm run dev
```
